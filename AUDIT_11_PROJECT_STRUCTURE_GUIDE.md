## Key File Explanations

### `src/App.js` — Why It Exists
The central routing file. Defines every route, applies all guards (BranchGuard, RequireAdmin, RequireStudent), and provides the PublicLayout wrapper. Any new route must be registered here.

### `src/contexts/AuthContext.js` — Why It Exists
Manages the entire authentication lifecycle. All components that need to know who is logged in, what their role is, or whether they are verified use `useAuth()`. This context owns the real-time Firestore listener on the user's profile document.

### `src/contexts/BranchContext.js` — Why It Exists
Branch selection is a prerequisite for almost everything. This context persists the selected branch to localStorage and provides the branch list from Firestore. All components that need to scope their data queries to a branch use `useBranch()`.

### `src/services/firestoreService.js` — Why It Exists (and Why It's a Risk)
All Firestore operations are centralized here to avoid duplicating query logic. However, at 3037 lines it has grown too large. This is the highest-risk file in the codebase — a bug here can affect any feature.

### `firestore.rules` — Why It Is Critical
This file defines who can read or write every document in the database. Any mistake here is a security vulnerability. It should be tested using the Firebase Emulator's rules testing tool before every deployment.

### `firestore.indexes.json` — Why It Exists
Firestore requires composite indexes for queries that filter on multiple fields. This file declares them. If an index is missing and a query uses it, the query will fail with an "index required" error in the console.

### `src/utils/registrationUtils.js` — Why It Exists
Support lesson registrations have a computed status (pending → verified → active → expired) that depends on the current date. This utility centralizes that logic so that the dashboard and admin pages always display the same status for the same registration.

## Naming Conventions

| Convention | Example | Meaning |
|---|---|---|
| PascalCase files | `StudentDashboard.js` | React components |
| camelCase files | `firestoreService.js` | Services, utilities, hooks |
| `use` prefix | `useAnnualFeeStatus.js` | Custom React hooks |
| `Page` suffix | `LoginPage.js` | Top-level route pages |
| `Modal` suffix | `AdminCreateStudentModal.js` | Overlay dialog components |
| `Form` suffix | `LanguageRegistrationForm.js` | Form components |
| `Service` suffix | `announcementService.js` | External data access |
| `Context` suffix | `AuthContext.js` | React context providers |
