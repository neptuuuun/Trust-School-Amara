# محتوى موقع التوثيق (للمطوّرين)

هذه المجلّة تحتوي على محتوى **مركز مساعدة Trust School Amara** (موقع التوثيق المستقل على المسارات `/help/*`)،
مكتوباً بصيغة Markdown عادية ويُعرَض ديناميكياً عبر المكوّنات في `src/docs/`.

## الملفات

| الملف | الدليل | المسار العام |
|---|---|---|
| `student.md` | دليل الطالب | `/help/student` (عام للجميع) |
| `admin.md`   | دليل المسؤول | `/help/admin` |
| `owner.md`   | دليل المالك  | `/help/owner` |

> هذا هو **المصدر الوحيد** لمحتوى الأدلّة. لا توجد نسخة أخرى في أي مكان.

## بنية المحتوى

- كل عنوان من المستوى الثاني (`## ...`) يصبح **مقالة** مستقلة لها صفحتها الخاصة، ومدخل في الفهرس الجانبي.
- العناوين من المستوى الثالث (`### ...`) تُبنى منها **قائمة المحتويات الجانبية** داخل المقالة.
- صناديق التنبيه: اقتباسات تبدأ بأيقونة `> 💡`, `> ⚠️`, `> ✅`, `> ℹ️`, `> 🔒`, `> 🛠️`, `> 🔴`.
- قسم عنوانه «الأسئلة المتكررة/الشائعة» يُعرَض كأكورديون تلقائياً.
- أي إشارة إلى مسار في التطبيق مكتوبة كشيفرة مثل `` `/admin/users` `` تتحوّل تلقائياً إلى **رابط** يفتح تلك الصفحة في التطبيق. كما تُربط بعض أسماء الصفحات (دروس الدعم، اللغات، الملف الشخصي…) تلقائياً — انظر `src/docs/appLinks.js`.

## كيف تُضيف مستنداً جديداً (سياسة خصوصية، شروط، دليل ولي أمر، دليل أستاذ، دروس، ملاحظات إصدار…)

1. أضِف ملف Markdown هنا، مثل `privacy.md`.
2. أضِف مدخلاً واحداً في `src/docs/registry.js`:

   ```js
   { id: 'privacy', title: 'سياسة الخصوصية', subtitle: 'كيف نحمي بياناتك',
     icon: 'Lock', group: 'legal', roles: ['public'], file: 'privacy.md', order: 90 }
   ```

3. لا حاجة لأي تعديل آخر: يظهر المستند في الصفحة الرئيسية ضمن مجموعته، ويدخل في البحث، وتُبنى صفحته ومقالاته والتنقل بينها تلقائياً.

## نقاط الوصول

- **الطلاب/العامة:** رابط «مركز المساعدة» في تذييل الموقع العام (يفتح `/docs` في تبويب جديد) — بدون تسجيل دخول.
- **المسؤول:** زر «مركز المساعدة» في ترويسة لوحة الإدارة (يفتح `/help/admin`).
- **المالك:** زر «مركز المساعدة» في ترويسة لوحة المالك (يفتح `/help/owner`).
